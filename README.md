# Download Speed Test

Консольный скрипт для измерения скорости скачивания с указанного URL.

Выполняет 10 последовательных GET-запросов и выводит:
- время выполнения и объём данных каждого запроса;
- среднее время запроса;
- общий объём полученных данных;
- среднюю скорость скачивания в Мбит/с.

## Установка

Потребуется Python 3 и библиотека requests.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

После запуска введите URL ресурса, который нужно скачать.

## Расчёт

Среднее время запроса = суммарное время запросов / 10.

Скорость скачивания в Мбит/с = общий объём в байтах × 8 / суммарное время в секундах / 1 000 000.

Время измеряется от начала запроса до полного получения тела ответа.
Объём считается без HTTP-заголовков и сетевых расходов.
